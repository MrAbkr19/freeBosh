Base de connaissances

Comment fonctionne la synchronisation hors-ligne PWA ?

FreeBosh enregistre les polycopiés consultés dans IndexedDB. Dès qu'un enseignant publie un nouveau document sur le réseau local, la PWA met à jour le cache automatiquement.

Comment importer des étudiants ou enseignants en masse ?

Rendez-vous dans la section « Import en masse » du panneau d'administration pour téléverser un fichier CSV préformaté.

Quelle est la taille maximale autorisée pour un document ?

La limite par défaut est de 50 Mo par fichier. Elle est configurable dans les Paramètres globaux de la plateforme.
